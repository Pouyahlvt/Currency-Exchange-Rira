# مبدل ارز 💱

یک ابزار ساده و واکنش‌گرا برای تبدیل ارز که با استفاده از React، TypeScript و Vite توسعه داده شده است.

این پروژه امکان تبدیل دلار آمریکا (USD) به ریال ایران (IRR) و بالعکس را با استفاده از نرخ لحظه‌ای ارز یا نرخ واردشده توسط کاربر فراهم می‌کند.

## ✨ امکانات

- **تبدیل دوطرفه ارز:** تبدیل دلار به ریال و ریال به دلار.
- **دریافت نرخ لحظه‌ای:** دریافت خودکار نرخ دلار از طریق یک API خارجی.
- **ورود دستی نرخ ارز:** امکان وارد کردن نرخ دلخواه دلار توسط کاربر.
- **به‌روزرسانی خودکار:** به‌روزرسانی نرخ دریافتی از API هر ۶۰ ثانیه.
- **مدیریت خطای API:** امکان استفاده از نرخ دستی در صورت در دسترس نبودن API.
- **طراحی واکنش‌گرا:** سازگار با نمایشگرهای دسکتاپ و موبایل.
- **قالب‌بندی اعداد:** نمایش اعداد با جداکننده هزارگان برای خوانایی بهتر.

## 🚀 راه‌اندازی پروژه

### پیش‌نیازها

برای اجرای پروژه باید Node.js و pnpm روی سیستم شما نصب باشند.

### نصب

ابتدا مخزن پروژه را دریافت کنید:

```bash
git clone https://github.com/USERNAME/currency-converter.git
```

وارد پوشه پروژه شوید:

```bash
cd currency-converter
```

وابستگی‌های پروژه را نصب کنید:

```bash
pnpm install
```

### اجرای نسخه توسعه

برای اجرای پروژه در حالت توسعه:

```bash
pnpm dev
```

### ساخت نسخه نهایی

برای ساخت نسخه Production:

```bash
pnpm build
```

## 💵 نرخ تبدیل ارز

این برنامه نرخ دلار آمریکا را از API زیر دریافت می‌کند:

[ Navasan API – Fiat Exchange Rates ](https://raw.githubusercontent.com/HosseinOdd/Navasan-API/main/data/fiat.json)

نرخ دریافتی از API بر اساس تومان است. برای تبدیل آن به ریال، از فرمول زیر استفاده می‌شود:

```ts
const usdToRial = usdToToman * 10;
```

همچنین کاربران می‌توانند نرخ دلار را به‌صورت دستی وارد کنند. در این حالت، برنامه به‌جای نرخ API از نرخ انتخاب‌شده توسط کاربر استفاده می‌کند.
